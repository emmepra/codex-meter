Codex Meter 0.3.3 shows the number of banked usage limit resets available to
the Codex CLI account, independent of the selected quota window.

- A confirmed zero is distinct from **Unavailable** when the CLI or service
  does not return a valid count.
- Retained counts are marked **Out of date** after a failed refresh or when
  they age out. Meter remains read-only and does not redeem resets.

The reset-count field is confirmed in the generated protocol schema for Codex
CLI 0.155.0-alpha.16. The earliest compatible stable CLI version and live
availability across accounts have not been verified. Older CLI responses
continue to show ordinary quota data and display reset availability as
**Unavailable**.

## Install

Download **Codex-Meter-0.3.3-macos-arm64.zip**, extract it, quit any older copy
of Codex Meter, and move the app to Applications. Requires **Apple Silicon,
macOS 13+**, and the Codex CLI signed in with ChatGPT.

The app remains **ad hoc signed and not notarized by Apple**. macOS may block
the first launch; see the [installation guide](https://github.com/emmepra/codex-meter/blob/v0.3.3/docs/INSTALL.md)
for Apple's per-app approval procedure. Verify the ZIP with `SHA256SUMS.txt` if
needed.
