Codex Meter now uses English throughout the app and its documentation.

- Translated panel labels, menus, tooltips, accessibility descriptions, error
  messages and CLI diagnostics.
- English date and number formatting, including when macOS uses another language.
- Added a contribution guide, issue forms, a pull request template and code owner
  routing. Contributions use fork-based PRs with automated tests and packaging.

Download **Codex-Meter-0.3.2-macos-arm64.zip**, extract it, quit any older copy of
Codex Meter, and move the new app to Applications. Requires **Apple Silicon,
macOS 13+**, and the Codex CLI signed in with ChatGPT.

The app remains **ad hoc signed and not notarized by Apple**. See the
[installation guide](https://github.com/emmepra/codex-meter/blob/v0.3.2/docs/INSTALL.md)
for first-launch instructions. Verify the ZIP with `SHA256SUMS.txt` if needed.
