Codex Meter 0.6.0 brings included quota and credit balance together in one compact panel.

- See included quota, its reset countdown and available credits in the same view. Credit balance keeps zero, unlimited, unavailable and out-of-date states distinct.
- Expand **Details** for recent credit consumption and estimated credit runway. Observations stay in memory and are scoped to a recognized personal account; they are balance changes, not a per-task billing ledger. **Credits in use** requires a recent observed balance decrease while a Codex quota window is exhausted.
- A fresh positive banked-reset count is green, including a single available reset.
- Fix continuous menu-bar indicator redraws caused by appearance changes.

## Update and install

From **0.5.3**, choose **Options → Check for Updates…** and confirm installation in the native update window. **Versions 0.5.2 and earlier need one manual upgrade:** download **Codex-Meter-0.6.0-macos-arm64.zip**, quit Meter and replace the copy in Applications.

Requires **Apple Silicon, macOS 13+**, and a **Codex CLI signed in with ChatGPT**. The app remains **ad hoc signed and not notarized by Apple**; signed in-app updates do not replace Developer ID notarization. See the [installation guide](https://github.com/emmepra/codex-meter/blob/v0.6.0/docs/INSTALL.md).
