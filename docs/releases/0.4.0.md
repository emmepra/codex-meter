Codex Meter 0.4.0 refreshes the compact interface and adds a manual update check.

- A readable used-quota number sits inside the menu-bar ring, without the percent sign.
- A green dot appears when fresh data reports at least one available reset. It is hidden for zero, missing or stale counts; exact counts remain in the panel and tooltip.
- The panel has an OpenAI service mark, a clickable Codex Meter signature and budget values that remain legible in dark mode.
- A dedicated application icon appears in Finder and update dialogs.
- **Check for Updates…** checks the latest stable release on GitHub only when requested. Updates open the release page for manual download; nothing is automatically installed.
- Update responses use strict version validation and fixed GitHub URLs. Redirects are rejected; no account or quota data is sent.

## Install

Download **Codex-Meter-0.4.0-macos-arm64.zip**, extract it, quit any older copy of
Codex Meter, and move the app to Applications. Requires **Apple Silicon, macOS 13+**,
and the Codex CLI signed in with ChatGPT.

The app remains **ad hoc signed and not notarized by Apple**. macOS may block the
first launch; see the [installation guide](https://github.com/emmepra/codex-meter/blob/v0.4.0/docs/INSTALL.md)
for Apple's per-app approval procedure. Verify the ZIP with `SHA256SUMS.txt`.

Reset availability depends on the CLI/service response. Missing counts remain
unavailable; Meter does not redeem resets. This is an independent community tool,
not an official OpenAI application.
