First downloadable release of Codex Meter, a compact macOS menu bar app for
Codex quota and reset times.

- Small usage ring and consumed percentage, with an optional ring-only mode.
- Remaining quota, reset countdown, daily/hourly budget and estimated runway.
- Fixed the panel's position: it stays directly below the menu bar when its
  content changes height.

## Install

1. Download **Codex-Meter-0.3.1-macos-arm64.zip** below and extract it.
2. Move **Codex Meter.app** to Applications and open it. Quit any older copy first.
3. The Codex CLI must already be installed and signed in with ChatGPT.

Requires **Apple Silicon and macOS 13+**. The interface is currently in Italian.
The ZIP contains a ready-to-run app; no compiler is needed to install it.

The app is **ad hoc signed, not notarized by Apple**. macOS may block its first
launch. See the [installation guide](https://github.com/emmepra/codex-meter/blob/v0.3.1/docs/INSTALL.md)
for Apple's per-app approval procedure or building from source.

`SHA256SUMS.txt` lets you verify the downloaded ZIP. The ZIP includes source
commit and compiler details in `BUILD-INFO.txt`. Offline tests and package
signature checks run in GitHub Actions before publication. Native panel layout
was tested locally; a full live reset cycle and all supported macOS versions
have not been tested.
