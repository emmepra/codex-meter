Codex Meter 0.5.2 is a small maintenance release.

- Update checks now enforce the 2 MiB response limit while downloading, including responses without a Content-Length header. Previously the limit was checked only after buffering the complete response.
- The README preview is rendered directly at 4× resolution, with a refreshed vector-derived logo and a controlled display width for sharper text.
- Security boundaries and the focused source review are documented in the repository.

## Install

Download **Codex-Meter-0.5.2-macos-arm64.zip**, extract it, quit the old copy, and replace the app in Applications. Requires **Apple Silicon, macOS 13+**, and a signed-in Codex CLI, standalone or bundled with Codex desktop.

Choose **Check for Updates…** for an immediate check. Download and installation remain manual.

The app is **ad hoc signed and not notarized by Apple**. See the [installation guide](https://github.com/emmepra/codex-meter/blob/v0.5.2/docs/INSTALL.md) for Apple's per-app approval procedure. Verify the archive with `SHA256SUMS.txt`.

The RSS provider remains a third-party trust dependency. The source review is not a guarantee of absence of vulnerabilities. Native launch at login has not been tested through a full logout/login cycle.
