Codex Meter 0.5.3 adds signed in-app updates and simplifies menu-bar notifications.

- **Check for Updates…** now opens a native Sparkle window to download, install and relaunch the app. Update metadata and archives are signed with Ed25519; archives are verified before extraction.
- Remove the blue update dot. Menu-bar dots now mean only available reset credits (green) or unread Tibo reset posts (amber).
- Background update checks remain quiet; an available version appears as **Install <version>…** in Options. Installing still requires your confirmation.

## One-time installation

Versions 0.5.2 and earlier cannot install automatically: download **Codex-Meter-0.5.3-macos-arm64.zip**, quit Meter, and replace the copy in Applications once. Future versions can then be installed from the update window.

Requires **Apple Silicon, macOS 13+**, and a signed-in Codex CLI. The app remains **ad hoc signed and not notarized by Apple**; update signatures do not replace Developer ID notarization. See the [installation guide](https://github.com/emmepra/codex-meter/blob/v0.5.3/docs/INSTALL.md). Native launch at login has not been tested through a full logout/login cycle.
