Codex Meter 0.5.0 adds native launch at login, quiet update checks and compact reset-post notices.

- **Launch at Login** is an opt-in native macOS setting, with an approval shortcut when needed. Login launches stay in the menu bar.
- Automatic update checks run silently at launch and every six hours while running. They can be disabled; updates still download and install manually.
- Three independent corner indicators: green for available reset credits, blue for an app update, amber for an unread Tibo post mentioning **reset**.
- A compact post row reads the public RSS feed for `@thsottiaux`, every 30 minutes. No X API key or login is required. Recent dates appear as Today/Yesterday; hover for details and click for the original post.
- Mark a post as seen without opening X. A subsequent increase between fresh reset-count samples also acknowledges the notice, without claiming a causal link. Initial counts, missing data and stale gaps never establish that link.
- Refresh moves into the header, with its timestamp on hover and a loading spinner. The duplicate footer is removed.

## Privacy and limitations

Reset posts use the third-party Nitter instance `x.noodl3.net`, not an official X/OpenAI service. It receives ordinary connection metadata such as your IP address. Meter sends no credentials, quota or account information. The feed can be unavailable, delayed or incomplete; cached/unavailable states are explicit. **Check Tibo’s Reset Posts** disables this feature. Only the latest matching post within seven days is shown. Post text and quota comparisons stay in memory; the last-read post ID is saved locally.

Keyword matches do not confirm a reset on your account. Meter never redeems credits. Native login behavior has not been tested through a full logout/login cycle.

## Install

Download **Codex-Meter-0.5.0-macos-arm64.zip**, extract it, quit the old copy, and replace the app in Applications. Requires **Apple Silicon, macOS 13+**, and Codex CLI signed in with ChatGPT.

The app is **ad hoc signed and not notarized by Apple**. See the [installation guide](https://github.com/emmepra/codex-meter/blob/v0.5.0/docs/INSTALL.md) for Apple's per-app approval procedure. Verify the archive with `SHA256SUMS.txt`.
