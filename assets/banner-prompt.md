# Brand artwork provenance

The current banner, social preview, logo and application mark are an original
geometric construction rendered by `scripts/make-icon.swift` with AppKit.
The source uses two circles and rounded arcs in teal and terracotta, with native
system typography on an ink background. No AI-generated bitmap, vendor logo,
account data or imitation interface is included.

The banner reads **Codex Meter**, **Both limits. One glance.**, and
**Codex + Claude Code · Native for macOS**. The artwork represents the two-service
identity; its arc lengths are decorative rather than quota measurements.

See [the brand guide](../docs/BRAND.md) for export sizes, palette and regeneration.
This filename is retained for existing documentation links. It replaces the
previous AI-generated banner and prompt; their provenance remains in Git history.
